The first website I ever built, I built by hand, because nobody was going to build it for me.

This was 2000. I was a teenager in Chicago hand-coding HTML in a text editor, publishing to a little corner of a shared host somebody let me borrow. The site ran on a publishing system I had written myself. I know I wrote it myself because the footer of every page announced the version number, and the version number was 3.1. A kid does not get to v3.1 without tearing the whole thing down and rebuilding it three times first.

There was no WordPress worth using. "Blog" was not a word yet. If you wanted a website that posted dated entries and kept them in an archive you could browse by year, you wrote the code that did that. So I wrote it, and then I wrote it again, and then again.

The writing on that site was the rambling of a teenager and it can stay buried. That was never the part that mattered. The part that mattered was the reflex underneath it: I wanted to publish, so I built the machine that let me publish. I did not wait for a company to show up and hand me a text box in exchange for my audience. The idea that publishing was something you asked permission for never occurred to me, because the only version of it I had ever known was the one where you made the tool yourself.

That reflex never went away. It just kept finding new names. Far Beyond the Stars was the same instinct pointed at a minimalism blog. Bogbook was the same instinct pointed at a protocol, rebuilt three times, same as the teenage site engine, each version throwing out one more thing that turned out to be optional. ANProto is where it lands now: a signed timestamp and a content hash, nothing else, publish it however you can reach a person.

The tools got better. The instinct is identical. The kid rebuilding his homemade site engine for the third time and the person stripping a protocol down to a signed hash are solving the same problem in the same way. How do I put this into the world without asking anyone for permission?

Here is what that era actually taught me about technology, and it is the one lesson I have never had to unlearn: the platform is optional. It was always optional. Somebody wrote the code that runs the platform you are renting space on, and that somebody can be you. The text box is not a gift. It is a trade, and you were already capable of building your own.

You are not waiting for the right tool. You are waiting for permission you already have.
