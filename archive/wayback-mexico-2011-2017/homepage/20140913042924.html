Processing Emails

September 12, 2014

Ever since I started running my own email server, I’ve had hella spam. Well, I had a lot of spam before, but then I had hella.

Since I’m commited to a distributed web, I had to figure out how to take this spam on myself. No one was going to help me do it (at the expense of my digital soul).

So started learning how to use Procmail.

Here’s what I did.

First I installed Procmail on my local machine.

% sudo pacman -Syu procmail.

Then I wired it into getmail, which I use with Mutt.

[destination]
type = MDA_external
path = /usr/bin/procmail

Next I made sure Procmail put my mail back where getmail used to put it.

MAILDIR=$HOME/mail 
PMDIR=$HOME/.procmail
DEFAULT=$HOME/mail/new
LOGFILE=$PMDIR/log
INCLUDERC=$PMDIR/general.rc

(I’m not sure the general.rc does anything, yet.)

Next I needed to create a procmail recipe to sort all of my spam to a new folder.

:0
* ^Subject.*(Ipad Just Became Perfect|ADP Invoice|Mortgage Loan|Amazon-eCard|MUST-READ NOW|NEVER have to Diet-Again)
spam/

Now, my own list is much longer, but I don’t want to appear to be a spam website, so I haven’t included the whole thing.

This is how I now combat spam on my email server.
