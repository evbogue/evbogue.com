Design Your Website


Learn the fundamentals of HTML5 and CSS3 with no prior knowledge required. I couldn’t find a decent resource to recommend to clients who wanted to learn how to design a website, so I wrote a decent resource. The Internet is filled with cheap and novel design tricks, but nowhere could I find a resource that taught you how to create a site from scratch while gaining the fundamental skills you need to build your web design knowledge from the ground up.

Minimum Viable Website + Reserva Templates


MVW is a 31-day project. The goal: learn all of the fundamentals you need to pilot a VPS. For the first 15 days, you’ll be building a minimum website using a VPS, a web server, and a static website generator. For the next 16 days, you’ll create a viable website. Fire your web designer, once and for all! Every day, you get one actionable thing to do, at the end of 31 days, you’ll have a website that you know how to own, operate, and build upon.

I built two website templates for use with Hakyll using reserva.css. A blog template and a book template. I use these website templates as the basis for my blog and products. Get access to the raw code when you buy Minimum Viable Website.
